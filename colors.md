# Colour Scheme 

Final palette. Use the CSS variable name, never the raw hex, so a colour change is
a one-line edit.

| Swatch | Hex | Variable | Role |
|---|---|---|---|
| Pale red | `#f4e4e8` | `--brand-tint` | Subtle brand background, selected-route highlight |
| Red | `#c20114` | `--brand-primary` | Navbar, primary buttons |
| Pale yellow | `#fef9c3` | `--yellow-bg` | Waiting badge background |
| Yellow | `#facc15` | `--yellow` | Waiting / alert accent ("needs driver") |
| Pale green | `#dcfce7` | `--green-bg` | Boarded badge background |
| Green | `#16a34a` | `--green` | Boarded / success |
| Off-white | `#fdfdfc` | `--surface` | Page background |
| Grey 100 | `#eaeaea` | `--surface-alt` | Card surface, dividers |
| Grey 200 | `#cecece` | `--border` | Borders |
| Grey 400 | `#a6a6a6` | `--text-muted` | Muted / disabled text |
| Grey 600 | `#6e6e6e` | `--text-secondary` | Secondary text |
| Near-black | `#100f0d` | `--text-primary` | Primary text |
| White | `#ffffff` | `--on-primary` | Text/icons on the red primary |
